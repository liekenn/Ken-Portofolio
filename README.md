# Kenrick Sierra Kisworo — Portfolio

Static multi-page HTML/CSS website. No JavaScript, framework, npm or build step.

## Preview
Open `index.html` in your browser (keep the `assets` folder alongside it).

## Publish to GitHub Pages
1. Create a public repository named `portfolio` (or `<your-username>.github.io` for a personal root site).
2. Upload the contents of this folder, not the outer folder: index.html, ppic.html, data-analytics.html, machine-learning.html, experience.html, style.css, assets, and .nojekyll (optional). Commit to main.
3. Settings > Pages > Build and deployment > Source > Deploy from a branch. Choose main and /(root), then Save.
4. Use the published URL displayed in Settings > Pages. For a repository called portfolio it normally looks like https://YOUR-USERNAME.github.io/portfolio/.
5. Link individual pages in your CV, for example /portfolio/ppic.html.

## Edit
HTML contains page copy; style.css contains all styles. Each page has shared header/footer markup. Edit a page directly in GitHub or in a text editor, then commit. Add certificate link in experience.html after uploading a shareable copy and checking its public access.

## Privacy and accuracy
This is a public website. It deliberately omits phone numbers, student IDs, raw records, complete group reports, unprovided certificates and full resume. Only cropped project output figures are published. Check permission from group members/university before publishing. Verify your LinkedIn URL. Group results are not solely individual accomplishments.
